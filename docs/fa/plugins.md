# افزونه‌های کورتکس هاب

افزونه‌ها داخل پوشهٔ `plugins/` هستند. هاب آن‌ها را مثل یک بستهٔ پایتون بار نمی‌کند. لانچر متغیرهای `CORTEX_*` را در محیط فرایند می‌نویسد و خود نرم‌افزار ساخت را با اسکریپت راه‌انداز همان ابزار باز می‌کند.

مرجع ماژول به انگلیسی (HTML): [../en/plugins/README.md](../en/plugins/README.md)

بازسازی HTML (پایتون با PySide6؛ خود مکس و بلندر لازم نیست):

```
python tools/build_docs.py
```

## مسیر کار تا افزونه

1. از داشبورد هاب یک کار را اجرا کنید.
2. `app.core.launcher` پوشهٔ کار و متغیرهای محیطی را می‌سازد و فایل اجرایی را از **Settings > Utilities** باز می‌کند.
3. مسیر خالی یعنی آن ابزار را استفاده نمی‌کنید؛ لانچر به‌جای اجرای مسیر خالی پیام می‌دهد.
4. اگر کار به یک نرم‌افزار قفل باشد، بقیهٔ ابزارها رد می‌شوند.

### متغیرهایی که هاب همیشه می‌گذارد

| متغیر | معنی |
| --- | --- |
| `CORTEX_PROJECT_ROOT` | ریشهٔ پروژه روی دیسک |
| `CORTEX_PROJECT_NAME` | نام پروژه |
| `CORTEX_TASK_ID` | شناسهٔ کار در اس‌کیو‌لایت |
| `CORTEX_TASK_NAME` | نام امن کار |
| `CORTEX_USER` | نام کاربری |
| `CORTEX_DEPT_NAME` | دپارتمان |
| `CORTEX_RENDER_ENGINE` | موتور رندر پروژه |
| `CORTEX_FPS` / `CORTEX_RES_W` / `CORTEX_RES_H` | نرخ فریم و وضوح |
| `CORTEX_FRAME_START` / `CORTEX_FRAME_END` | بازهٔ اختیاری |
| `CORTEX_ENTITY_TYPE` / `CORTEX_ENTITY_NAME` | شات یا اَست |
| `CORTEX_WORK_PATH` | پوشهٔ کار همان تسک |

## تری‌دی‌اس مکس

اجرا: `3dsmax.exe -U PythonHost plugins/3dsmax/startup.py`

راه‌انداز یک فایل `.mxp` تمیز داخل `_max_system` می‌نویسد، پوشه‌های خالی مکس را از ریشهٔ پروژه جمع می‌کند، بعد داک کورتکس را نشان می‌دهد: آخرین فایل، لودر، انتشار، ذخیرهٔ نما.

## بلندر

اجرا: `blender.exe --python plugins/blender/startup.py`

نرخ فریم و وضوح را از محیط می‌گیرد، اگر PySide6 نباشد نصب می‌کند، نوار شناور کورتکس را باز می‌کند (لودر، انتشار، ذخیره).

## مایا

اجرا: مایا با `PYTHONPATH` که به `plugins/maya/` اضافه شده تا `userSetup.py` خودش اجرا شود.

نرخ فریم، وضوح و ورک‌اسپیس را تنظیم می‌کند و شلف بومی **Cortex** را می‌سازد (آخرین فایل، لودر، انتشار، …).

## هودینی

اجرا: هودینی با `HOUDINI_PACKAGE_DIR` روی `plugins/houdini`، `PYTHONPATH` روی `plugins/houdini/scripts`، `JOB` برابر پوشهٔ کار. فایل بسته `cortex_houdini.json` همین مسیرها را به هودینی می‌دهد. `scripts/456.py` هنگام ساخت یا باز شدن هیپ اجرا می‌شود (نام فایل قرارداد هودینی است). شلف کورتکس از `toolbar/cortex.shelf` می‌آید.

## فتوشاپ

اجرا: خود فتوشاپ، بعد یک فرایند جدا با `python plugins/photoshop/startup.py`. نوار ابزار داخل مفسر فتوشاپ نیست؛ با API پایتون فتوشاپ حرف می‌زند. اگر بستهٔ `photoshop-python-api` نباشد همان راه‌انداز نصبش می‌کند.

## دوبعدی مشترک

`plugins/common/publisher_2d.py` پنجرهٔ هاب برای انتخاب PSD/PNG/XCF و ثبت در خط تولید است؛ وقتی انتشار از خود هاب باشد نه از نوار داخل ابزار.
