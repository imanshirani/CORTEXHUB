# راهنمای کورتکس هاب

نرم‌افزار رومیزی برای استودیوهای سه‌بعدی و دوبعدی: تخصیص کار، باز کردن ابزارهای ساخت با زمینهٔ پروژه، و انتشار نسخه از داخل همان ابزار.

مخزن: https://github.com/imanshirani/CORTEXHUB

مستندات انگلیسی API هاب: [../en/app.html](../en/app.html)

افزونه‌ها (مکس، بلندر، مایا، هودینی، فتوشاپ): [plugins.md](plugins.md) — مرجع HTML انگلیسی: [../en/plugins/README.md](../en/plugins/README.md)

## نیازمندی‌ها

- ویندوز
- پایتون ۳٫۱۰ یا جدیدتر روی PATH (هنگام نصب پایتون گزینهٔ «Add python.exe to PATH» را بزنید)

## نصب

یک‌بار `Install_Cortex.bat` را اجرا کنید. پایتون را چک می‌کند و بسته‌های `requirements.txt` را نصب می‌کند.

یا در خط فرمان:

```
python -m pip install -r requirements.txt
```

## اجرا

`Start_Cortex.bat` را بزنید، یا:

```
python app/main.py
```

این فایل فقط برنامه را باز می‌کند؛ پیش‌نیاز نصب نمی‌کند.

## ورود پیش‌فرض

پس از نصب خالی، مدیر اولیه این است (بعد از ورود از تنظیمات عوض کنید):

- نام کاربری: `admin`
- گذرواژه: `123456`

## مسیر ابزارها

در **Settings > Utilities** مسیر فایل اجرایی هر نرم‌افزار را بگذارید. مسیر خالی یعنی آن ابزار را استفاده نمی‌کنید؛ فقط همان‌هایی را پر کنید که استودیو نیاز دارد.

لانچرهای آماده: تری‌دی‌اس مکس، مایا، بلندر، هودینی، فتوشاپ.

## ساختار پوشه‌ها

| مسیر | نقش |
| --- | --- |
| `app/` | رابط هاب (PySide6) و هستهٔ اس‌کیو‌لایت |
| `plugins/` | افزونه‌های مکس، مایا، بلندر، هودینی، فتوشاپ |
| `resource/icons/` | آیکون برنامه و نرم‌افزارها |
| `docs/en/` | مرجع API به انگلیسی |
| `docs/fa/` | همین راهنما به فارسی |

فایل اس‌کیو‌لایت محلی در `app/core/` ساخته می‌شود. پستگرس برای نصب بعدی روی سرور یا ابر کنار گذاشته شده است.

## افزونه‌ها

از داشبورد یک کار را اجرا کنید. هاب متغیرهای محیطی `CORTEX_*` و پوشهٔ کار را می‌نویسد، بعد نرم‌افزار را با افزونهٔ هماهنگ باز می‌کند.

جزئیات هر ابزار، فایل‌ها و متغیرها: [plugins.md](plugins.md)

## نکتهٔ دیتابیس

اگر قبلاً با کاربر `iman` کار می‌کردید، همان فایل قدیمی عوض نمی‌شود. کاربر `admin` فقط وقتی ساخته می‌شود که جدول کاربران خالی باشد.
